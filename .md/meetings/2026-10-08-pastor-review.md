6. **찾아오시는 길** — 기존엔 교회소식 아래. 따로 빼도 좋음.

## 2. 항목별 대화 상세

### 2-1. 교회소개 (0:00–1:00)
- 카테고리는 기존 구성에 맞추되, 새가족등록·온라인 새가족등록은 새 사이트에서 이미 독립 섹션으로 빠져 있으니 **교회소개에서는 제외**.
- 섬기는 이들은 넣고, 예배시간·찾아오시는 길은 따로 빼는 것이 좋겠다고 함.
- 들어가야 할 것: **원로목사, 담임목사, 섬기는 이들, 양육/훈련**.
- 시안의 **연혁**은 기존 사이트에 없던 항목 → "있어야 하는데 없었구나" 반응, 유지. 카테고리는 추후 추가/삭제 가능하니 일단 진행.

### 2-2. 예배 (1:00–2:10, 7:40–9:40, 32:30–35:00)
- 기존 분류의 의미: 주일예배 = 담임목사 설교, 금요 생수의 강·월삭예배 = 담임목사 설교, 특별집회 = 외부 강사, 수요/새벽/주일5부 = 부교역자 설교. 이 구분이 유지돼야 함.
- 기존 사이트는 "전체" + 수요/새벽/주일5부 하위 필터 탭 구조. 클릭 시 유튜브 영상이 재생됨. 이 구조를 따를지 새로 설계할지는 미결(O2).
- **운영 현황**: 유튜브 업로드는 목사님이, 홈페이지 게시글 등록은 담당자(조상복 선생님?)가 **매번 수동**. 당신은 연동돼 있는 줄 알았음. "유튜브에만 올리면 사이트에 자동 반영"이 가능하다고 하자 목사님 호응 — **공수 절감 핵심 포인트** (D3).
- 당신 의견: 이 사이트의 주 콘텐츠는 결국 설교 영상 → 어떻게 잘 보여줄지가 핵심 고민.
- **금요 생수의 강을 부교역자가 하면 올릴 카테고리가 없다**는 점을 목사님이 발견(O1). "부교역자 설교는 올리지 않을 텐데" 정도로 넘어감.
- **예배 시간표**: "청년예배"는 **"수요 청년예배"**로(요일을 앞에). 수요예배 찬양은 실제 7:20 시작이나 주보에 7:30으로 나가므로 당분간 그대로(O6). 영어예배가 대예배 줄에 섞여 있어 어색 → **대예배 / 주일학교 예배**로 구분하기로(D9).

### 2-3. 다음세대 (2:10–3:05, 15:55–17:00, 32:55–33:30)
- 묶음(영아·유치 등) 풀어서 **부서별 개별 항목**, **영어예배부 추가**, **엘림가족부 삭제**(없어진 부서).
- 세부 페이지 디자인·내용을 정해 **영어예배부 하나라도 만들어** 보여드려야 설명이 됨 → 샘플 선제작(D5).
- 자료(사진·소개)는 많지 않음. 필요한 것 요청하면 목사님이 보내 줌.
- 기존 사이트의 "상단 큰 사진 + 하단 카테고리" 레이아웃은 답습할 필요 없음. 간사 소개·부서 사진이 본문에 들어가므로 상단 사진 의미가 적을 수 있음 → 레이아웃 재고(O4).
- 목사님 전망: 각 부서에 요청해야 해서 **다음세대 제작이 가장 오래 걸릴 것**. 나머지는 기존 것 옮겨 채우면 됨.

### 2-4. 교회소식 (3:50–4:50, 17:00–17:30)
- **성복의 뜰** = 행사 관련 영상·홍보 영상. "지난 건 사실 다 필요 없는 것".
- **사진첩**엔 행사사진보다 **칼럼**이 올라가고 있음 → 새로 만들 땐 컨셉을 정해서. 당신 제안: 앨범(교구·행사 사진)과 칼럼 분리 → 긍정(O5).
- **공지사항은 실제로 안 씀** — 광고는 모두 주보에 들어감. 게시판류는 외부인 글 우려로 운영 안 함 → 삭제(D6).
- **주일광고 = 예배 전 광고 영상**. 조정환 목사님이 매주 업로드. 새 사이트에선 카테고리·디자인만 만들면 담당자가 매주 갱신 (관리자 기능 필요).

### 2-5. 자료실 (4:50–5:30)
- 시트지: 주일 설교 / 시리즈 설교(시리즈별 분류) / 명절·절기 → 비슷하게 만들면 됨.
- **악보는 저작권 때문에 올리기 어려움. 서식은 따로 없음** → 시안의 악보·서식 다운로드 제외(D7).
- 대부분 기존 콘텐츠 활용 + 디자인만 신경 쓰면 됨.

### 2-6. 찾아오시는 길 (5:30)
- 시안에서 이미 따로 빼놓은 것 괜찮음.

### 2-7. 메인 청년부 유튜브 / 찬양 (5:40–6:30, 23:50–24:35)
- 현재 메인 영상 영역이 **올리브워십**(청년부 유튜브 아님). 새 사이트에서 그대로 쓰긴 애매.
- 주일 찬양(3부 찬양 등)이 홈페이지에 조금씩 업로드될 예정 → 그걸 연결하고 **타이틀만 "성복의 찬양"류로** 교체(D8). 청년부 자체 콘텐츠는 많지 않음.
- 홈페이지 음악은 "누르면 소리 나오게" 해뒀는데, 진입 시 자동재생은 기능적으로 안 되고 끄기 어려워 **안 하는 게 낫다**(D10).

### 2-8. 다음세대 "별 선택" 인터랙션 / 모바일 (6:30–7:40)
- 목사님: 데스크톱 스크롤에선 좋은데 **폰에서 위로 올리기가 걸림**. 본인은 어떻게든 되지만 어른들은 힘들 것.

## 3. 문서에 없던 논의

### 3-1. 히어로·메인 비주얼 (9:40–15:50)

- **표어**: "삶의 기쁨과 소망을 주는 교회"가 대표 표어라 넣음. 예배당 앞 올해 표어도 넣었지만 임시.
- 당신의 설계 의도: 첫 방문자(교회를 알아보는 사람)가 주 사용자 → **교회가 어떤 곳인지 전경부터** 보여주는 히어로.

- 기존 사이트 히어로는 **유튜브 임베드**라 컨트롤러가 노출됨. 제대로 하려면 mp4 원본 필요. 기존 업체 산출물은 화질이 낮아 교회 측(재원?)이 화질을 올려 줬던 이력.
- 사진이 부족하면 사진을 빼거나 비주얼을 키우거나 일반 사진으로 대체하는 방향.
- 처음 교회를 찾는 사람에겐 **소속 교단** 정보가 중요 → 뒤쪽에 함께 들어가면 좋겠다는 목사님 의견.

### 3-2. 섬기는 이들 사진·디자인 톤 (28:00–31:40)
