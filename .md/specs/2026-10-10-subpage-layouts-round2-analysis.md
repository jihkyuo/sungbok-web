# 서브페이지 레이아웃 2라운드 — 페이지별 분석

**날짜**: 2026-10-10 · **상태**: 머리 = **S1 확정**(20종 시트 비교 후). 본문 구조(F·G·H·I)는 아래 분석대로 유지, 섹션 작업(B~F)에서 실데이터로 확정.

> **결과**: 1라운드 셸 5종(A~E)은 전부 탈락. 2라운드에서 머리만 따로 20종(S1~S20) 비교 → **S1(에디토리얼 좌정렬 + 알약)** 채택. S6·S8·S10이 탈락한 공통 원인은 "독과 서브내비의 위계 부재(파란 알약 둘, 간격 0, 정렬 불일치)" — 이후 규칙: 독 = accent 유일, 서브 = 먹색/bold, 독과 24px 이상. 모바일 메뉴(M1 아코디언 / M2 드릴다운)는 미확정.
**전제 수정**: 1라운드의 "공통 셸 + 본문 교체"는 폐기. 공유하는 것은 라우트 구조·네비 데이터·독 아래 여백뿐이고, **레이아웃은 섹션(콘텐츠 유형)별로 각각 설계**한다.

## 공통 규율 (요소 하나하나에 적용)

- 모든 요소는 **독자의 질문에 답하거나**(정보 기능) **명확한 시각 의도**가 있어야 한다. 둘 다 아니면 뺀다. 1라운드의 11px 모노 라벨("다음세대")은 독이 이미 섹션을 표시하므로 정보 기능이 없고 읽히지도 않아 **삭제**.
- 글자 크기 하한: 본문 16px · 보조 정보 14px · 캡션 13px. 모노 서체는 데이터(날짜·시간)에만, 그것도 13px 이상.
- 독(fixed, 상단 18px + 높이 ~54px) 아래 콘텐츠 시작 = 112px(모바일 100px). 1라운드의 240px 공백은 근거 없음.
- 형제 페이지 전환 장치는 **그 섹션의 콘텐츠가 요구하는 형태**로 — 부서는 연령 순서(타임라인), 예배는 분류(세그먼트), 교회소개는 목차(세로 목록), 소식은 종류(언더라인 탭). 알약 탭(B)은 교회소개 › 담임목사의 기준안.

**레이아웃 결정**

3. **정보 스트립** — 모이는 시간 / 장소 / 대상 3칸. 라벨 14px, 값 20px bold. 스캔 한 번에 읽히게.
4. **부서 사진** — 와이드(21:9) 한 장. 분위기 전달. 머리 위가 아니라 정보 다음에 두는 이유: 사진은 ④번 질문이라서.
