# 홈 영상 섹션 분석 — 라이브 스테이지 + 광고 릴

**날짜**: 2026-10-11 · **상태**: 시안 확정(LiveBand card1 · ReelBillboard) → 정식 승격 완료(2026-10-18).

> **결론**: 홈의 두 영상 영역을 용도로 분리한다. **위 = 라이브 스테이지(LiveStage)** — 성복교회 공식 유튜브 채널에서 라이브가 켜지면 자동 재생(음소거), 아니면 이요셉 담임목사 최신 설교(클릭 재생). **아래 = 광고 릴(NoticeReel)** — 예배 광고 영상이 순서대로 자동 로테이션. 둘 다 유튜브 채널을 단일 소스로 자동 연동하며, 구 사이트처럼 영상을 사이트에 다시 올리는 작업은 없앤다. 자동화에 필요한 세 조건(라이브 감지·최신 설교 판별·광고 목록)은 모두 채널 실데이터로 확인됐다.

## 1. 배경

- 현재 홈([src/app/page.tsx](../../src/app/page.tsx))에는 `VariantCombo`(위: 설교 벤토 그리드 / 아래: 21:9 "청년 예배" 띠)와 `TurntableStage`(청년 LP) 두 영상 위젯이 있다. 원래 둘 중 하나를 고를 계획으로 남겨둔 것인데, 두 영역을 모두 쓰되 용도를 나누기로 했다.
- 구 사이트의 주일예배(`bo_table=0201`)·금요 설교(`0202`) 게시판은 담당 목사님이 유튜브 영상을 사이트에 다시 올리는 방식이다. 0201 최신 글이 사도행전 강해 62강인데 유튜브에는 64강까지 있어 2주 밀려 있다. 이중 업로드를 없애는 것이 이번 작업의 운영 목표다.
- 모든 데이터는 `.env`의 `NEXT_PUBLIC_YOUTUBE_CHANNEL_ID`(UClz4pOT6Kmuy8MvR3cyHPjA, @sungbokchurch) 채널에서 2026-10-11 확인.

## 2. 섹션 정의

| 섹션 | 코드명 | 역할 | 상태 |
|---|---|---|---|
| 라이브 스테이지 | `LiveStage` | 라이브 우선, 없으면 담임목사 최신 설교 | `live`(자동재생·음소거) / `vod`(썸네일+클릭 재생) |
| 광고 릴 | `NoticeReel` | 예배 광고 영상 로테이션 | 메인 1개 자동재생(음소거) + 대기 큐, 끝나면 다음 |
| 청년 LP | `TurntableStage` | 청년 예배 영상 (기존 유지) | — |

**순서**: 라이브 스테이지 → 광고 릴 → 청년 LP. (ADR 0002의 "영상 = 첫 방문자의 분위기 미리 보기"에 맞춰 라이브/설교를 위에, 교인용 광고를 아래에.)

`VariantCombo` 아래 띠의 "청년 예배" 콘텐츠는 LiveStage로 바뀌며 빠지고, 청년 영상은 `TurntableStage` 하나로 수렴한다.

**화면 라벨 주의**: "광고"는 교회 용어(announcement)지만 1순위 타깃(첫 방문자)에게는 상업 광고로 읽힐 수 있다. 코드명·피드백 호칭은 "광고 릴"로 두고, 화면 노출 라벨("이번 주 안내" 등)은 카피 단계에서 결정.

## 4. 라이브 스테이지 — 연동 규칙

**선별**
- `live`: 업로드 목록 상위 N개를 `videos.list`로 조회해 `snippet.liveBroadcastContent === 'live'`인 것. 설교자 무관, 라이브가 항상 최우선.
- `vod`: 제목이 `| 이요셉 목사`로 끝나거나 설명에 `*설교: 이요셉 목사`가 있는 최신 업로드. 제목 규칙이 1순위(당일 반영), 재생목록은 보조(2일 지연). 주일 설교만 쓰려면 `liveStreamingDetails.actualStartTime`이 KST 일요일인 것으로 한정.
- 제목 파서(`시리즈 | 제목 | 본문 | 설교자`, 3~4분절)는 순수 함수 → TDD 대상. 규칙이 깨지면 원제목 그대로 폴백.

**쿼터**: `search.list`는 100유닛이라 분 단위 폴링 불가(일 한도 10,000). `playlistItems.list` + `videos.list`는 각 1유닛 → 1분 폴링 시 일 2,880유닛. 폴링은 **서버에서 한 번**(Route Handler 또는 서버 컴포넌트 + revalidate 60초), 클라이언트는 탭이 보일 때만 그 결과를 받는다. 방문자 수와 무관하게 비용 고정, API 키는 서버에 남김. (현재 홈 쪽 `YoutubeInitialize`는 브라우저 gapi + `NEXT_PUBLIC` 키 노출 → 방문자 수만큼 쿼터 소모. `domains/worship-video/api/server.api.ts`의 googleapis 서버 호출을 확장하는 쪽이 맞다.) 구현: Route Handler `/api/home-video` + `fetch next.revalidate=60`(googleapis 는 Next Data Cache 를 거치지 않아 미사용). 호출 3회/분 = 일 4,320유닛

**방송 중 ≠ 예배 중**: 금요 스트림은 예배 3시간 전부터 켜지고, 주일 오전은 1~3부 사이 공백까지 한 스트림이다. 라이브 신호에 `domains/home/data/worshipTimes.ts` 시간표(±여유)를 교차해 예배 시간 창에서만 `live`로 전환한다. "다음 라이브 안내"도 유튜브 "예정"이 아니라 이 시간표에서 계산.

**재생**: 자동재생은 브라우저 정책상 음소거 시작. 소리는 버튼(사용자 제스처)으로만 — `TurntableStage`의 `enablejsapi` + postMessage `unMute` 패턴 재사용. `vod`는 썸네일 포스터 + 재생 버튼만 두고 클릭 시 iframe 삽입(클릭이 제스처라 소리 있는 재생 가능, iframe 선로딩 없음).

**검증 필요**: 진행 중 라이브가 업로드 목록에 뜨는지 실제 라이브 시각(예: 월 05:15 새벽예배)에 1회 확인. "예정" 항목이 뜨는 것은 확인됨.

## 5. 광고 릴 — 연동 규칙

- **소스 = 유튜브 재생목록 하나**(관리자가 "홈 광고" 생성, ID를 사이트 설정에). 목록에 있는 것만 보여주고 **날짜 필터는 두지 않는다** — 오래된 광고라도 관리자가 남기면 보이고, 빼면 사라진다. 관리자 의도가 규칙보다 우선.
- 재생목록은 **공개 또는 일부공개(unlisted)** 여야 API 키로 읽힌다(비공개 불가). 안의 영상도 일부공개로 올리면 구독자 피드에 섞이지 않고 임베드·썸네일은 정상.
- **순서 = 목록 순서**. 유튜브는 새 영상을 목록 끝에 붙이고 관리자가 드래그로 바꿀 수 있다. 코드는 정렬 없이 받은 순서대로. "맨 위 = 최신"을 원하면 관리자가 끌어올리는 것이 운영 규칙.
- 영상 0개면 섹션 숨김, 1개면 메인만. "준비 중" 류 빈 상태 카피 금지(톤 원칙).
- 재생: 동시 iframe은 메인 1개. 큐는 API 썸네일 이미지. 끝 감지는 IFrame API `ENDED` → 다음 로드. 클릭 확대는 소리 켜서 패널/모달로(FirstVisit 모프 패널과 같은 결).
- 시안 단계에서는 광고 목록이 없으므로 채널의 임의 재생목록(예: "특별집회 및 행사")을 연동해 본다.

## 6. 레이아웃 분석 — 광고 릴 비율

현재 `VariantCombo` 위 벤토(1440 기준):

| 타일 | 크기 | 비율 | 16:9 손실 |
|---|---|---|---|
| 좌 메인 (7/12 × 2행) | 670×416 | 1.61 | 높이 10% |
| 우 와이드 (5/12 × 1행) | 474×200 | 2.37 | 높이 25% |
| 우 소형 (2/12, 3/12) | 180×200, 278×200 | 0.9, 1.4 | 세로형 |

유튜브 iframe은 `object-cover`가 안 돼 비율이 다르면 덮기 계산(`TurntableStage`의 coverW/H)이 필요하다. **광고 슬롯은 전부 16:9로 고정**하면 그 해킹이 사라진다. 광고가 세로(9:16)로 제작되면 전제가 바뀌므로 제작 비율 확인이 선행.

"메인 플레이어 + 대기 큐 로테이션"에 맞는 방향(시안 라운드의 논제 후보, 코디의 선호 아님):
- 플레이어 + 세로 큐 리스트(16:9 썸네일 + 제목 행, 맨 위 = 재생 중 + 진행 바). 개수 가변, 끝나면 위 행이 빠지고 다음이 올라옴.
- 플레이어 + 하단 가로 필름스트립(모바일 스와이프 친화, 섹션이 길어짐).
- 현재 + 다음 1장만 엿보이는 2업 캐러셀(정보량 적음).
- 카드 덱 스택(큐 내용이 안 보여 비추천).

## 7. 결정 사항

**확정(사용자)**
- 라이브는 설교자 무관 최우선. 없으면 이요셉 담임목사 설교.
- 광고 = 재생목록 멤버십 그대로, 날짜 필터 없음.
- 순서: 라이브 스테이지(위) → 광고 릴(아래).
- 시안 변형 5개로 1라운드. 변형 착수 지시는 사용자가 한다.

**미결**
1. 광고 영상 제작 비율(16:9 가정).
2. `vod` 선별: 주일 설교 고정 vs 이요셉 목사 최신(금요 포함).
3. 라이브 범위: 전체 라이브(주 20시간 가까이 ON AIR) vs 주일예배만.
4. 운영 합의: 미디어팀의 제목 규칙 유지 + "홈 광고" 재생목록 생성·관리.
5. 화면 노출 라벨("광고" vs "안내").
