# design-preview — 시안 탐색·라이브 프리뷰

성복교회 웹(Next.js 15 App Router + TS + Tailwind 4)에서 레이아웃·효과·인터랙션
시안을 **라이브 프리뷰 라우트**로 만들어 사용자가 직접 만지며(hover·scroll·반응형)
고르게 하는 작업 절차. 이 파일은 **얇은 절차 + 가드레일**이다 — 상세 컨벤션은
정본 문서를, 품질·다양성 기준은 메모리를 *가리킨다*. 여기서 복제하지 않는다.

## 0. 정본 먼저 로드 (매번, 복사 금지)

시안을 만들기 전에 반드시 읽고 시작한다.

1. **방법론 정본**: [.md/workflow/prototype-preview.md](../../../.md/workflow/prototype-preview.md)
   를 Read. 디렉토리 구조·`page.tsx` 핵심·전용 포트·재사용 헬퍼(AmbientVideo·
   useScrollProgress)·자기점검·확정 후 정리가 전부 거기 있다.
2. **품질/다양성 기준**: 디자인 시안 관련 메모리(`feedback-hero-design-bar`,
   `feedback-avoid-templating`, `feedback-design-preview-route`, `feedback-copy-tone`)
   를 회상해 적용한다. 메모리는 **가드레일**이지 재조합할 틀이 아니다.
3. **진단 먼저**: 현재 구현의 문제를 한 문장으로 못박고, 콘텐츠 모델(성격 다른
   콘텐츠는 각자 라벨로 분리)을 확정한 뒤 시안에 들어간다.

문서·메모리 내용이 코드 현실과 어긋나면 **현재 코드를 정본으로** 보고 어긋남을 보고한다.

## 1. 시안 설계 — 다양성 게이트

> 거부 히스토리에서 온 가드레일. 어기면 "다 비슷, 틀에 갇혔다"로 일괄 거부된다.

- **시안마다 bespoke.** 레이아웃·주제·무드·색 지배·타이포 위계·모션 종류를 전부
  다르게. 같은 빌딩블록 세트를 효과만 바꿔 리스킨 ❌. 공유 가능한 건 데이터
  (이미지·CTA href)뿐, 스타일/타입/팔레트/구성은 공유 금지.
- **결을 나눠 묶기.** "정적 N + 도전 N"처럼 성격을 갈라 달라고 한다. 적은 수라도
  매끄럽고 완성도 높은 게 다수의 거친 시안보다 낫다.
- **브랜드 적합.** 성복교회는 밝은 하늘색(b1 `#f6fafe`) 차분·따뜻·정중 브랜드.
  검정/네이비 "테크" 톤, 풀블리드 다크 화면전환은 비선호. 컨테인드·라이트한
  2026 트렌드(벤토·디콘스트럭티드·소프트 메시·키네틱 타이포·글래스모피즘) 선호.
- **레퍼런스 새로 탐색.** 교회에 국한 말고 awwwards·Codrops 등 범용에서. 막히면
  사용자 아이디어를 문자보다 *의도*로 해석.
- **시안마다 단문자 코드(A·B·C…)** 부여 — URL `?v=a`·하단 탭·좌상단 배지·설명줄에
  모두 표시해 코드로 빠르게 지칭하게 한다.

## 2. 프리뷰 라우트 — 컨벤션 게이트

상세 디렉토리 구조·`page.tsx` 슬롯 패턴은 정본 문서 B절을 따른다. 매번 어겨
교정당하는 핵심만 다시 못박는다:

- **위치**: 프리뷰는 `src/app/<name>-preview/page.tsx`(`'use client'`), 변형은
  **대상 위젯 옆 `_variants/`**. registry **0번 = 현재 구현**(기본 선택·비교 기준).
- **단독 ❌.** 실제 후속 섹션을 `page.tsx` 그대로 재현해 붙인다(등장·전환·여백을
  봐야 결정 가능). 섹션만 떼서 평가하지 않는다.
- **한 화면 = 한 시안.** 세로로 쌓지 말고 고정 탭바(`fixed`+`z-[9999]`) + `?v=`
  동기화. 탭 전환은 `history.replaceState` 로 `?v=` 만 갱신, **스크롤 위치 유지**
  (`scrollTo(0)` 금지). 동적 라우트 `[variant]/page` 는 풀리로드·404 나니 금지.
- **전역 안 건드림.** `globals.css` 손대지 말고 시안 전용 keyframe/효과는 프리뷰
  `page.tsx` `<style>` 에 `sp-` 프리픽스로 국소 정의. 임시물은 커밋하지 않는다.
- **빈 포트로 띄움** (여러 세션 동시 사용, 3000·3001·3002·3007 등 점유) — `pnpm preview` 가
  빈 포트를 자동 탐색해 기동한다:
  ```bash
  pnpm preview          # 빈 포트 자동 탐색 후 dev 기동
  pnpm preview 3030     # 3030부터 탐색
  ```
  `pnpm dev -- -p <n>` 는 `--` 가 next 로 잘못 전달돼 실패하니 쓰지 말 것.

## 3. 모션 품질 — 품질 게이트

> "동작이 이상하면 애초에 안 본다." 잔카나는 시안은 내용 보기 전 탈락.

- **transform·opacity만** 애니메이트(컴포지터 스레드). `filter: blur()` 애니메이션·
  `clip-path` 스크럽·rAF 안 `offsetWidth`/`getBoundingClientRect` 읽기(레이아웃
  스래싱) 금지.
- 스크롤 연동(사용자 제어 모션)은 **reduced-motion 에서도 끄지 말 것**. `if(reduced)
  {return}` 로 통째 끄면 OS '동작 줄이기' 사용자에게 히어로가 멈춰 보인다. 자율
  루프 모션만 절제한다.

## 4. 자기 점검 (사용자에게 보여주기 전)

gstack `browse` 로 슬롯을 캡처해 깨진 곳·콘솔 에러를 먼저 확인한다. 상세 명령은
정본 문서 D절. **browse daemon은 다른 세션과 공유**될 수 있으니 `goto` 직후·
스크린샷 직전후 `$B url` 로 활성 탭을 가드하고 어긋나면 재시도한다.

## 5. 전달

URL + 시안별 `?v=` 코드 + 한 줄 설명을 준다. 카피는 `feedback-copy-tone`(사실
진술, 영업 톤 ❌) 준수.

## 6. 확정 후 정리

- 승자 1안을 본 위젯(`<Widget>/index.tsx`)에 이식.
- `src/app/<name>-preview/` 라우트와 `_variants/` 폴더를 **통째로 삭제**. 임시
  자산·stand-in 도 함께 제거. **승자 이식분만** 커밋(임시물은 커밋하지 않는다).
- git 스테이징·커밋은 **사용자가 명시적으로 지시할 때만** (프로젝트 git 규칙).
