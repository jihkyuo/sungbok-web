# 예배 설교 영상 (`/worship/sunday` 등)

예배 메뉴는 **영상을 보러 들어오는 곳**이다. 관리자는 유튜브에 올리기만 하고, 사이트는 유튜브에서 읽어 자동으로 분류한다.
화면은 시안 G(2026-11-12 확정) — 페이지 안 플레이어 · 유튜브식 설명란 · 「설교 목록」(시리즈) · 찾기 목록.

> 계획·결정 배경: [specs/2026-11-12-worship-sermon-g-plan.md](../specs/2026-11-12-worship-sermon-g-plan.md)

## 운영 규칙 — 유튜브에 이렇게 올리면 된다

| 무엇 | 규칙 | 사이트에서 |
|---|---|---|
| 어느 예배 페이지 | 예배별 **유튜브 재생목록**에 넣는다(주일예배 = 「주일 예배 설교」) | 그 페이지에 나온다. 연결은 코드 설정([worshipPages.ts](../../src/domains/worship-video/config/worshipPages.ts)) |
| 시리즈 | 제목을 `시리즈 이름 N \| 제목 \| 본문 \| 설교자` 로 | 「설교 목록」에 시리즈 칩이 생기고 `N편` 으로 묶인다 |
| 단편(절기·주제) | 제목 첫 칸에 회차 번호가 없으면 단편 — `성찬식 \| 제목 \| 본문 \| 설교자`, `제목 \| 본문 \| 설교자` | 「단편 설교」 칩 하나로 모인다. 첫 칸(성찬식 등)은 분류 표시로 보인다 |
| 설교일 | 설명 **첫 줄**에 `2026년 10월 25일 …` | 그 날짜로 정렬·표시. 없으면 유튜브 **업로드 날짜**를 쓰고 「업로드 2026.10.25」로 표시(설교일이 아닐 수 있어서) |
| 설명 | 자유롭게 | 플레이어 아래에 그대로(첫 줄이 날짜면 그 줄은 숨김). `#` 으로 시작하는 줄은 색만 다르게 |

- 본문·설교자 칸은 빠져도 된다(`시리즈 N | 제목 | 설교자`). 형식 밖 제목은 제목 전체가 그대로 보이고 단편으로 간다 — 목록에서 빠지지는 않는다.
- 시리즈 이름은 띄어쓰기만 달라도 같은 시리즈로 묶는다(「마태복음 강해」·「마태복음강해」 → 가장 최근 편의 표기). 회차는 세 자리까지 — 「송구영신예배 2026」의 연도는 회차로 읽지 않는다.
- 네 칸을 다 채우면 마지막 칸은 직분과 상관없이 설교자로 읽는다(초청 설교자 「홍길동 집사」, 「성복교회 이요셉 목사」).
- 시리즈 안의 순서(회차 목록·이전/다음 편)는 날짜가 아니라 **회차 번호**로 정한다.
- 설정에 없는 재생목록(예배 찬양, 장별 마태복음 등)은 어디에도 나오지 않는다.
- 반영 시점: 유튜브 응답 1시간 캐시 + 페이지 10분 재생성 → 올린 뒤 **최대 약 1시간 10분**.

## 구조

```
유튜브 playlistItems(snippet,contentDetails) ──1시간 Data Cache──▶ worshipVideo.server.ts
   제목·설명 읽기(sermonParse) → Sermon[] (최신순) + 설명 본문(Map)
        │
        ├─ 페이지(ISR 10분): widgets/SermonLibrary → prefetchSermonLibrary → HydrationBoundary
        │      목록 전체 + 최신 설교의 설명 1편을 HTML 에 싣는다
        └─ Route Handler: /api/worship-video/library?page=   (서버가 못 실었을 때 화면이 받음)
                          /api/worship-video/description?page=&v=   (고른 영상의 설명 — 목록에 있는 영상만)
화면(features/SermonPage): 고르기·검색·정렬·무한스크롤은 받은 목록으로 화면에서(sermonList) — 유튜브를 다시 부르지 않는다
```

| 파일 | 맡은 일 |
|---|---|
| `config/worshipPages.ts` | 예배 페이지 ↔ 재생목록 id. 다른 예배 페이지를 열 때 한 줄 추가 |
| `api/sermonParse.ts` | 제목·설명 → 시리즈·회차·본문·설교일(순수) |
| `api/sermonList.ts` | 정렬·검색(「12장」 → `12:`)·시리즈 묶기·이전/다음 편·표시 문구(순수) |
| `api/worshipVideo.server.ts` | 유튜브에서 모으기(서버 전용). 업로드 시각 → 한국 날짜는 여기서(Temporal, [ADR 0012](../decisions/0012-date-temporal-and-admin-libraries.md)) |
| `api/useSermonLibrary.ts` · `useVideoParam.ts` | 화면 훅. 고른 영상은 주소 `?v=영상id`(공유·뒤로가기). `useSearchParams` 로 읽지 않는다 — 정적(ISR) 페이지의 서버 HTML 이 통째로 빠진다. 라우터가 바꾼 주소(같은 페이지 링크)는 Suspense 안의 빈 부품(`useVideoParamRouterSync`)이 알려 준다 |
| `components/features/Sermon*` | 플레이어·설명란(SermonInfo)·설교 목록(SermonSidebar)·찾기 목록(SermonSearchList) |

## 화면 규칙

- **플레이어**: 처음엔 포스터(이미지 한 장) — 누르면 그 자리에 유튜브 플레이어(`youtube-nocookie`). 목록에서 고른 영상은 포스터 없이 바로 재생. 공유 주소(`?v=`)로 들어오면 포스터부터. 포스터로 재생을 시작하면 그 영상을 주소에 남긴다(방문 기록은 쌓지 않음) — 보는 중에 새 설교가 올라와도 화면이 바뀌지 않게. 「재생 중」 배지는 실제로 재생을 시작한 뒤에만 붙는다.
- **설교 목록**: 최근 시리즈 칩 4개 + 「전체 N개」(연도별 고르기). 휴대폰은 회차를 옆으로 미는 한 줄, 태블릿은 3칸 + 화살표, PC(lg 이상)는 플레이어 옆 세로 목록.
- **찾기 목록**: 시리즈 선택(왼쪽) · 검색(오른쪽) · 최신순/오래된 순. 처음 12편, 끝에 닿으면 12편씩(무한스크롤). 다 보이면 아무 문구도 남기지 않는다.
- 영상을 고르면 플레이어가 화면에 다 보이지 않을 때만 플레이어로 올린다.
- 설교 시트지: `SermonInfo` 의 `sheetHref` 자리만 있다 — 관리자 업로드가 생기면 연결한다.

## 미결·다음

- 금요·특별집회·수요새벽 페이지: `worshipPages.ts` 에 재생목록을 더하고 `<SermonLibrary page="…" />` 를 쓰면 같은 화면이 나온다(재생목록 후보는 그 파일 주석).
- 재생목록이 매우 길면(새벽예배 800편대) 목록 전체를 HTML 에 싣는 방식을 다시 본다. 설명 API 도 요청마다 목록 전체를 캐시에서 다시 조립하므로(유튜브 쿼터는 쓰지 않음) 그때 함께 본다.
